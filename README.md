# Обои с Google Календарём

Тёмный фон рабочего стола и вертикальный список событий Google Календаря справа. Приложение EduLog удалено из центральной области. Для встроенного Google-виджета применяется CSS-фильтр тёмного отображения; он также меняет оттенки цветов событий.

## Установка

```powershell
git clone https://github.com/meshcheryakovaa/wallpaper_engine_dashboard.git "D:\Wallpapers\EduLog"
```

Откройте `D:\Wallpapers\EduLog\index.html` в Wallpaper Engine. Календарь `alexanderrichard00@gmail.com` уже подключён в проекте, часовой пояс — `Asia/Yekaterinburg`. Ручной ввод не требуется. Календарь должен разрешать общедоступный просмотр событий. Общедоступность открывает события другим людям; рекомендуется отдельный календарь для обоев.

## Обновление

```powershell
git -C "D:\Wallpapers\EduLog" pull --ff-only
```

После обновления перезагрузите обои в Wallpaper Engine. Подробности и ограничения — в README.txt.
